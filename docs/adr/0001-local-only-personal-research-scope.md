# 研究范围以本地模型为主，但架构不绑定任何模型或模型服务商；选型只看"免费"和"是否合适"

Memex 是个人的研究与学习项目，不用于商业目的。目标是研究怎样构建一个能在某个领域里自我学习、建立 Worldview 的系统。研究和评测都以本地模型为主，不把云端大模型当作对照组：用户已经熟悉云端大模型的使用体验，不需要再拿它来对比。成功的标准是"同一个模型，随着经验积累在某个领域里越来越好"。

这是研究范围上的选择，不是架构上的限制。按依赖倒置原则（见 ADR 0008），换一个本地模型，甚至换成任意一家云端模型服务商的大模型，都只需要改配置，不影响系统运行。

## Consequences

- 不设 B-large 参照组，也没有"差距弥合率"指标。同一组对比实验里，所有 Baseline 使用同一个模型。
- 组件选型只看两点：是否免费，以及是否与系统匹配。许可证是否属于 OSI 开源不再作为门槛，所以 jevos、iii 这类组件都可以作为候选。
- 前人工作（例如 NeSyFS）可以直接借鉴，甚至实现成一个可对比的 Cognitive Strategy。
- **补充（ADR 0013）**："只看是否免费、是否合适"只适用于**使用**。Memex 要分发给他人，所以凡是随 Memex 一起分发的组件，都必须允许再分发。
