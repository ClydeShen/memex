# 只用本地模型；选型只看"免费"和"是否合适"

Memex 是个人的研究与学习项目，不用于商业目的。目标是研究怎样构建一个能在某个领域里自我学习、建立世界观的系统。因此不引入任何云端大模型，连作为评测参照也不用：用户已经熟悉云端大模型的使用体验，不需要再拿它来对比。成功的标准是"同一个本地模型，随着经验积累在某个领域里越来越好"。

## Consequences

- 不设 B-large 参照组，也没有"差距弥合率"指标。所有 Baseline 都使用同一个本地模型。
- 组件选型只看两点：是否免费，以及是否与系统匹配。许可证是否属于 OSI 开源不再作为门槛，所以 jevos、iii 这类组件都可以作为候选。
- 前人工作（例如 NeSyFS）可以直接借鉴，甚至实现成一个可对比的 Cognitive Strategy。
