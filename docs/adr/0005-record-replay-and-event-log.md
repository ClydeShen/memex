# 用录制和回放实现复现，以追加写入的事件日志作为持久化基础

本地模型在 GPU 上运行时，即使 temperature 为 0、seed 固定，批处理也会改变浮点运算的累加顺序，所以不保证每次输出相同。我们也没有找到能证明 llama.cpp 对批大小不敏感的资料。因此复现不能依赖 seed：每次调用 Provider 的输入和输出都录制下来，回放时直接使用录制的结果。

持久化的基础是一个只追加写入的本地事件日志，图存储和记忆都是从日志派生出来的视图。这样快照、回放、崩溃恢复和后台整合都建立在同一个机制上。Claim 上的时间使用模拟器的时间，延迟指标使用真实的系统时钟，两者分开记录。
