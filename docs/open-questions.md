# 待决问题

这里记录讨论中还没有定下来的事项。定下来的决定按重要程度写进 `docs/adr/` 或 `GLOSSARY.md`，并从本文件中删除。

## 需要决定

1. **第一个真实领域。** Micro World 之后，需要一个有真实数据、并且能判断结果对错的领域，用来检验 Domain Pack 的格式。
2. **Micro World 对 Agent 隐藏什么。** 有两个选项：只隐藏世界状态；或者连因果规则和动作效果也一起隐藏，让 Agent 自己摸索。后者更贴近"建立世界观"的目标，但也更难。如果规则是公开的，T1–T3 就很接近规划问题，B-sym 可能占优。
3. **Intuition 模型的校准。** Laya 的基础权重在零样本测试中接近随机水平，而且刚发布时置信度偏高。提议：MVP 阶段允许在开发集上做校准（按问题类型拟合温度参数，不改权重），微调推迟到 Beta。Laya 和 jevos 都是 A/B 对比的候选。
4. **旧 `master` 分支怎么处理。** 新历史和旧 `master` 没有共同祖先。可以把默认分支换成新分支，也可以用新历史覆盖 `master`。旧代码保存在 `archive/memex-v1` 分支。
5. **流程精简。** 提议：保留可复现、实验隔离、对照组、学习曲线和基本统计（均值、置信区间）；简化 release 数据集的保密流程、72 小时稳定性测试，以及 Alpha/Beta/RC/V1 的正式关卡。
